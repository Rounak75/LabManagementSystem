# Lab Management System (Desktop)

A medical laboratory management system desktop application used by phlebotomists, receptionists, and lab technicians to manage visits, test results, and administrative workflows.

## Mode
Operate

## Core Jobs
- Fast data entry for new patient visits (Notion-like simplicity).
- Scanning barcodes and printing labels.
- Handling test results and generating reports.
- Syncing offline-first data to the cloud.

## User Constraints
- Users often have high cognitive load. Interfaces must be extremely clean, reducing visual noise.
- Medical context requires high trust and professionalism.
